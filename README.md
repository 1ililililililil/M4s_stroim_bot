# MCHS AI Admin Bot V3

## Что нового в V3

### 👨‍🚒 Интерактивная админ-панель
Команда `/panel` открывает меню:

- 💬 Новые комментарии
- 📊 Статистика
- 🤖 AI режим
- 🛡 Модерация
- 🧠 Память
- ⚙️ Настройки
- ℹ️ Помощь

### 🤖 Режимы
- Manual — только ручное подтверждение.
- Smart Auto — автоматический ответ только на безопасные комментарии с высокой уверенностью.

### 🧠 Память
- `/remember текст`
- `/knowledge`
- `/forget ID`

### 📊 Healthcheck
`GET /health`

## Replit Secrets
BOT_TOKEN
OPENROUTER_API_KEY (или OPENAI_API_KEY)
ADMIN_IDS

## Запуск
```bash
python -m app.main
```

## Подключение Telegram
1. Создайте бота через BotFather.
2. `/setprivacy` → Disable.
3. Добавьте бота в связанную с каналом группу обсуждений.
4. Для удаления сообщений дайте права администратора.
5. Каждый администратор должен сначала написать боту `/start`.
6. Откройте `/panel`.
