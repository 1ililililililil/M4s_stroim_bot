Нужно доработать существующий Telegram-бот MCHS AI Admin Bot V3.

ГЛАВНАЯ ЦЕЛЬ:

Бот должен автоматически анализировать все новые комментарии в связанной Telegram discussion group и самостоятельно отвечать только на те комментарии, которые действительно требуют ответа.

ВАЖНО:

- сначала изучи текущую архитектуру проекта;
- не переписывай работающий проект с нуля;
- сохранить текущие Telegram handlers;
- сохранить PostgreSQL + SQLAlchemy AsyncIO;
- использовать существующий AI-клиент;
- не менять Secrets и API-ключи;
- изменения должны быть минимальными.

==============================
ЛОГИКА РАБОТЫ
==============================

Каждый новый комментарий:

1. Получить Telegram update.

2. Проверить:
- сообщение не от самого бота;
- комментарий ещё не был обработан;
- нет повторного update.

3. Выполнить предварительную проверку:
- SPAM;
- ссылки;
- реклама;
- токсичность.

4. Передать комментарий в AI для анализа.

AI должен определить:

- требует ли комментарий ответа;
- является ли это обычной реакцией;
- является ли это вопросом;
- является ли это SPAM/рекламой;
- стоит ли отвечать от имени канала.

==============================
АВТОМАТИЧЕСКИЙ ОТВЕТ
==============================

Если комментарий не требует ответа:

→ ничего не публиковать.

Если это обычная реакция:

Например:
«🔥»
«Круто»
«Спасибо»
«👍»

→ ничего не публиковать.

Если это SPAM:

→ использовать существующую логику модерации;
→ не генерировать обычный AI-ответ.

Если комментарий является вопросом или требует содержательного ответа:

→ автоматически сгенерировать ответ;
→ автоматически опубликовать его ответом на исходный комментарий.

==============================
СТИЛЬ ОТВЕТОВ
==============================

Ответы должны соответствовать Telegram-каналу:

«МЧС | Мы Чего-то Строим»

Стиль:

- дружелюбный;
- живой;
- разговорный;
- профессиональный, когда это необходимо;
- без слишком официального языка;
- без длинных AI-текстов;
- отвечать естественно, как автор канала.

Ответ должен быть коротким и содержательным.

Если AI не уверен в фактах:

→ не выдумывать информацию;
→ не давать недостоверный ответ.

==============================
КОНТЕКСТ
==============================

Если доступен текст исходного поста:

AI должен анализировать:

Текст поста
+
Текст комментария

чтобы понимать контекст вопроса.

Например:

Пост:
«Будни пожарного. Работа на пожаре.»

Комментарий:
«А сколько обычно длится?»

AI должен понимать, о чём идёт речь.

==============================
АВТООТВЕТЫ
==============================

Сохранить команды:

/auto_on
/auto_off

Если автоответы выключены:

→ анализировать комментарии;
→ не публиковать ответы автоматически.

Если автоответы включены:

→ автоматически отвечать на комментарии, которые требуют ответа.

==============================
ЗАЩИТА ОТ ДУБЛЕЙ
==============================

Обязательно защитить от:

- повторного Telegram update;
- повторного анализа одного комментария;
- двойной публикации ответа;
- ответа на сообщения самого бота;
- бесконечного цикла ответов.

Один комментарий должен получить максимум один автоматический ответ.

==============================
БАЗА ДАННЫХ
==============================

Использовать существующую PostgreSQL базу.

Сохранять минимум:

- chat_id;
- comment_id;
- текст комментария;
- результат AI-анализа;
- требуется ли ответ;
- опубликованный ответ;
- статус обработки;
- время обработки.

Все Telegram ID должны оставаться BIGINT.

==============================
ОШИБКИ AI
==============================

Если OpenRouter/OpenAI недоступен:

- бот не должен падать;
- комментарий не должен получать пустой ответ;
- ошибка должна быть записана в лог;
- polling должен продолжать работать.

==============================
ПРОВЕРКА
==============================

После изменений проверить:

1. Обычный вопрос:
→ AI анализирует;
→ автоматически отвечает.

2. Простая реакция:
«🔥🔥🔥»
→ не отвечает.

3. Благодарность:
«Спасибо!»
→ не отвечает.

4. Вопрос по теме поста:
→ учитывает контекст поста;
→ отвечает.

5. SPAM:
→ не отвечает обычным AI-ответом.

6. Повторный update:
→ второй ответ не публикуется.

7. Сообщение от бота:
→ игнорируется.

8. Ошибка AI:
→ приложение продолжает работать.

После этого выполнить:

python -m pytest -q

Затем запустить:

python -m app.main

Проверить:

- Telegram polling;
- PostgreSQL;
- AI-анализ;
- автоматический ответ;
- защиту от дублей;
- healthcheck.

В конце показать отчёт:

Telegram polling: OK/ERROR
PostgreSQL: OK/ERROR
AI-анализ: OK/ERROR
Автоматические ответы: OK/ERROR
Контекст поста: OK/ERROR
SPAM moderation: OK/ERROR
Защита от дублей: OK/ERROR
Healthcheck: OK/ERROR
Tests: OK/ERROR

Перед изменениями кратко перечисли файлы, которые будут изменены.

При первой новой ошибке остановись и покажи полный лог.
