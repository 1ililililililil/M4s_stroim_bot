Задача: проверить полный путь работы Telegram-бота с комментариями.

Выполни последовательно:

1. Проверь конфигурацию:
   - TELEGRAM_BOT_TOKEN / BOT_TOKEN
   - OPENAI_API_KEY
   - ADMIN_IDS

   - SESSION_SECRET, если используется

2. Проверь requirements.txt и убедись, что установлены необходимые зависимости для текущей архитектуры.

3. Проверь подключение к PostgreSQL:
   - подключение через SQLAlchemy AsyncIO;
   - используется asyncpg;
   - URL корректно преобразуется в postgresql+asyncpg:// при необходимости;
   - sslmode корректно адаптируется для asyncpg;
   - таблицы создаются без ошибок.

4. Проверь запуск приложения командой:
   python -m app.main

5. После запуска проверь, что:
   - Telegram polling стартует;
   - бот получает updates;
   - healthcheck доступен;
   - приложение не завершается с ошибкой.

6. Проверь обработку входящего сообщения из Telegram.
   Найди существующие handlers и middleware и проследи полный путь:
   Telegram update
   → handler
   → проверка пользователя/администратора
   → модерация
   → AI-анализ
   → формирование ответа
   → отправка ответа
   → запись результата в PostgreSQL.

7. Проверь AI-интеграцию:
   - используется OPENAI_API_KEY из Secrets;
   - ключ не выводится;
   - запрос к AI имеет обработку ошибок;
   - при временной ошибке AI бот не должен падать;
   - ответ AI должен быть безопасно ограничен по длине для Telegram.

8. Проверь работу с комментариями Telegram.
   Учитывай, что комментарии канала фактически приходят через связанную группу обсуждений.
   Убедись, что бот способен получать сообщения из discussion group при наличии соответствующих прав и privacy settings.

9. Проверь модерацию комментариев:
   - запрещённый/токсичный контент;
   - спам;
   - ссылки;
   - нормальные сообщения;
   - вопросы пользователей;
   - сообщения, на которые AI должен ответить.

10. Проверь, что бот НЕ отвечает сам на свои сообщения и не создаёт бесконечный цикл ответов.

11. Проверь команды администратора, которые уже существуют в проекте.

12. Если найдёшь техническую ошибку:
   - исправляй только минимально необходимый код;
   - не удаляй существующие функции;
   - не переписывай проект с нуля;
   - после каждого исправления повторно запускай тест.
