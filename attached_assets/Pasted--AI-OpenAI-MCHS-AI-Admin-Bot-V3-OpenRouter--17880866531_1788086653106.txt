Нужно заменить AI-провайдер OpenAI в проекте MCHS AI Admin Bot V3 на OpenRouter с бесплатными моделями.

Цель:
Бот должен продолжить работать с AI без пополнения OpenAI API и без использования OPENAI_API_KEY.

ВАЖНО:
Не переписывай проект.
Не меняй Telegram handlers.
Не меняй database models.
Не меняй модерацию.
Не меняй admin commands.
Не удаляй существующую AI-архитектуру.
Внеси только минимальные изменения в AI provider/configuration layer.

Используй Secret:

OPENROUTER_API_KEY

Если Secret отсутствует, остановись и сообщи, что его нужно добавить в Replit Secrets.

Настрой OpenRouter API как OpenAI-compatible provider.

Используй:

base_url:
https://openrouter.ai/api/v1

Модель:

openrouter/free

Требования:

1. Сначала проанализируй существующий AI-модуль и найди место, где сейчас создаётся OpenAI client.

2. Сделай минимальную замену провайдера:
   OpenAI API
   →
   OpenRouter API.

3. OPENAI_API_KEY больше не должен быть обязательным для запуска бота.

4. OPENROUTER_API_KEY должен читаться только из Secrets.

5. Никогда не выводи API-ключ в логах.

6. Сохрани существующий интерфейс AI-модуля, чтобы Telegram handlers не пришлось переписывать.

7. Сохрани текущие:
   - system prompt;
   - логику анализа комментариев;
   - модерацию;
   - генерацию ответов;
   - fallback при ошибке AI.

8. Добавь корректную обработку ошибок:
   - timeout;
   - 429 rate limit;
   - недоступность модели;
   - ошибка API.

9. Если OpenRouter временно недоступен, бот не должен падать.
   Он должен использовать существующий fallback.

10. Проверь, что бот не отвечает сам себе и не создаёт цикл сообщений.

11. После изменения выполни:
   - установку необходимых зависимостей, только если они реально нужны;
   - python -m pytest -q;
   - python -m app.main.

12. После успешного запуска выполни реальный AI-тест через OpenRouter.

Тестовый комментарий:

"Здравствуйте! Расскажите, пожалуйста, чем занимается МЧС и почему работа пожарных важна?"

Проверь цепочку:

Комментарий
→ AI-модуль
→ OpenRouter API
→ бесплатная модель
→ AI-ответ
→ обработка ответа
→ запись результата в PostgreSQL.

В конце покажи отчёт:

Telegram polling: OK / ERROR
PostgreSQL: OK / ERROR
OpenRouter AI: OK / ERROR
Реальный AI-ответ: YES / NO
Moderation: OK / ERROR
Fallback: OK / ERROR
Healthcheck: OK / ERROR

Также перечисли изменённые файлы и объясни причину каждого изменения.

ВАЖНО:
Не заявляй, что AI работает, пока не будет выполнен реальный запрос к OpenRouter.
Не меняй остальные части проекта без необходимости.
Если появится новая ошибка — остановись на первой новой ошибке и покажи полный лог.
После успешного запуска не останавливай работающий бот.
